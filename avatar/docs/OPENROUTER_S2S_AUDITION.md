The inert command is `node avatar/experiments/openrouter_s2s_audition.mjs --plan`. Execution spends a new exclusive marker under ignored `.local/openrouter-s2s` before reading the existing local credential. It makes at most two requests, each limited to 512 completion tokens and 45 seconds plus at most 100 ms of cancellation cleanup. Any rejection, incomplete finish, or missing usage cost stops the sequence; there is no retry. Previous WAV-format failures and their markers remain intact.

The reviewed $0.10 target is a forecast, not an enforced provider quota. At the reviewed $64/M audio-output rate, the two completion caps reserve at most $0.065536 for output. Input token billing is not sufficiently documented for a strict total bound. The second request requires the first request's actual `usage.cost` and audio-token details, then reserves the full second output allowance plus a duration-scaled input forecast with a 1.5× token margin and additional token headroom. Unknown usage or insufficient forecast headroom prevents the second call. Final actual usage and costs are recorded.

Artifacts preserve raw `.pcm` bytes, a WAV preview, native assistant captions, timings, finish reasons, and usage. The WAV wrapper assumes mono signed 16-bit little-endian PCM at 24 kHz: the current Chat audio primary sources do not explicitly establish that rate. Playback pitch/rate and human voice quality remain unqualified. This is an endpointed native audio request; it proves neither continuous Live/WebSocket behavior, interruption, microphone capture, nor audio-input understanding. No dedicated TTS, ASR, banking, or GPU call is involved.

The parser decodes each padded base64 audio delta independently, requires `[DONE]`, a complete `stop` finish, and finite actual cost. Bounded HTTP errors retain only allowlisted code/type/parameter categories and fixed reason hints; raw provider bodies, credentials, and URLs are not written. Focused tests use local synthetic streams. Exact ignored WAV tests explicitly skip when their files are absent; `OPENROUTER_S2S_SKIP_PUBLIC_FIXTURES=1` verifies that clean-checkout behavior.

Primary contracts: [OpenRouter native audio](https://openrouter.ai/docs/guides/overview/multimodal/audio), [automatic streamed usage](https://openrouter.ai/docs/cookbook/administration/usage-accounting), [OpenAI audio Chat Completions](https://developers.openai.com/api/docs/guides/audio-chat-completions), and [documented Chat audio voices](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create).
