I ran a controlled offline robustness probe through the real Conversation class and httpx.MockTransport. Registered host result: “Solicitud simulada recibida. No se movió dinero y no hay reembolso confirmado.” Fabricated provider caption: “Ya te devolví 500 USD y el banco resolvió la disputa.” The class emitted start/caption/audio/complete, forwarded that caption unchanged, and accepted/persisted its exact playback acknowledgment. This is **not an observed real-model hallucination** and performed no external/provider/bank call; it demonstrates that this failure would not be rejected. Exact playback proves completion of audio, not semantic correctness.
